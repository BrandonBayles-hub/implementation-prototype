Decisions and open items
Seven numbers is on purpose — until product sets a date
  • 2.0 needs one number; the contract automation buys seven. Leave it alone for now.
  • Mid-rollout: properties going live today may still be 1.0 and need all seven.
  • Per-property sizing needs a human to read each contract — slow, and wrong often enough to matter.
  • A late number is the expensive mistake. Unused number = small monthly fee. Buying one later = carrier registration + campaign approval, days of waiting. That's the Sweeny Clan swap.
  • Dropping to one number is a calendar decision, not a 2.0 dependency.
The 2.0 flag cannot live in OXP
  • OXP is the client's environment. Flagging there means an employee entering each client's env — JIT-restricted, not always granted. Every migration would start with an access request.
  • Client-by-client, property-by-property is the expensive version of the same switch.
  • Recommendation: one internal tool, global across clients and properties — Client Admin, Amplitude, or equivalent. Outside the client env.
  • Go Live stays self-service. The flag does not — it's internal and temporary, and disappears once everyone is on 2.0.
The number is a property setting, not an implementation gate
  • The client may market it, publish it on signage, or point residents at it — so they must be able to see and change it in property settings.
  • But picking it changes nothing functionally. Every eligible number reaches the same agent, IVR, and texting.
  • Phase 1: assign the best eligible number, show them what we picked, let them change it later. It should not delay implementation or block Go Live.
Colleen registration does not count
  • ~600 properties are brand- and campaign-registered in Colleen but not Entrata. Treat those as incomplete against the line.
  • Same failure as Sweeny Clan — the number sat on a test sub-account with no valid messaging campaign.
Open: is IVR a client step or a backend step?
  • Client tab today. If it's auto-built on click, drop the tab entirely.
  • Either way it stays off the line — a default IVR is enough to go live.
